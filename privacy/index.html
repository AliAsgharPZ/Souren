سیاست حریم خصوصی

آخرین به‌روزرسانی: ۱۲ نوامبر ۲۰۲۶

سورن برای ورود و تأیید مالکیت نشانی ایمیل از کد یک‌بارمصرف (OTP) استفاده می‌کند. این صفحه توضیح می‌دهد اطلاعات چگونه در این فرایند پردازش می‌شوند.

استفاده از Gmail API

سورن از حساب sourenotp@gmail.com و Gmail API صرفاً برای فرستادن پیام‌های حاوی کد یک‌بارمصرف به نشانی‌ای که کاربر وارد کرده است استفاده می‌کند. برنامه به صندوق ورودی Gmail دسترسی نمی‌گیرد، ایمیل‌های دریافتی را نمی‌خواند و از این دسترسی برای ارسال خبرنامه یا پیام تبلیغاتی استفاده نمی‌کند.

کدهای یک‌بارمصرف

کد OTP شش‌رقمی است و حداکثر ۱۰ دقیقه اعتبار دارد. کد به‌صورت متن ساده در پایگاه داده نگهداری نمی‌شود؛ فقط هش و نمک آن برای بررسی کد واردشده ذخیره می‌شود. پس از تأیید موفق یا پایان مهلت، رکورد کد حذف یا منقضی می‌شود. برای محدودکردن سوءاستفاده، زمان ارسال مجدد و شمار تلاش‌های ناموفق نیز موقتاً ثبت می‌شوند.

اطلاعات حساب

برای ارائه حساب مشترک در وب‌سایت، سورن و آریو، اطلاعاتی مانند نام کاربری، نام نمایشی، نشانی ایمیل تأییدشده و هش گذرواژه در فضای ذخیره‌سازی امن سرویس نگهداری می‌شود. نشست ورود نیز با شناسه‌ای تصادفی و زمان انقضا مدیریت می‌شود. داده‌های نمایه مانند پسندیده‌ها و نشان‌شده‌ها، در صورت استفاده از این قابلیت‌ها، ممکن است همراه حساب ذخیره شوند.

اشتراک‌گذاری و نگهداری

اطلاعات احراز هویت برای اجرای ورود، ثبت‌نام، اتصال ایمیل و حفظ نشست حساب استفاده می‌شوند. سورن اطلاعات ورود به Gmail یا کلیدهای فنی سرویس ایمیل را در برنامهٔ اندروید یا مرورگر کاربر قرار نمی‌دهد. این اطلاعات محرمانه فقط در تنظیمات سمت سرور نگهداری می‌شوند.

تماس

برای پرسش دربارهٔ حریم خصوصی می‌توانید از مخزن رسمی سورن در گیت‌هاب با نگه‌دارندهٔ پروژه تماس بگیرید.
